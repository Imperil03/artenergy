Menú

El menú de ArtEnergy incluye brochetas, platos caseros, ensaladas, jugos naturales, cócteles y bebidas. Hay un menú infantil y puedes encargar una tarta con antelación para tu celebración.

En las visitas habituales a ArtEnergy se aplica un consumo mínimo de comida y bebidas. El importe completo se destina a platos y bebidas del menú; no se cobra una entrada aparte.
