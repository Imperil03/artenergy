Antes de venir

¿Puedo venir con niños?

Sí. Los niños deben estar bajo la supervisión constante de adultos.

¿Podemos poner nuestra música?

Sí, puedes usar tu propia lista de música tras acordarlo con la administración.

¿Dónde podemos comer y beber?

Hay zonas específicamente habilitadas para comer y beber.

¿Podemos reservar todo el espacio solo para nuestro grupo?

La posibilidad de uso privado del espacio y su coste se consultan por separado. Una visita habitual no implica que todo el recinto esté cerrado para otros visitantes.

¿Qué normas se aplican en las piscinas?

Está prohibido saltar o zambullirse en las piscinas.
