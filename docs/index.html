Что важно знать

Можно ли приезжать с детьми?

Да. Дети должны находиться под постоянным присмотром взрослых.

Можно ли включать свою музыку?

Да, свой плейлист можно использовать после согласования с администратором.

Где можно есть и пить?

Для еды и напитков предусмотрены специально выделенные зоны.

Можно ли арендовать всю территорию только для своей компании?

Возможность приватного использования площадки и его стоимость обсуждаются отдельно. Обычное посещение не предполагает, что вся территория будет закрыта для других гостей.

Какие правила действуют у бассейнов?

Прыгать и нырять в бассейны запрещено.
