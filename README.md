# ArtEnergy

Статический многостраничный сайт площадки ArtEnergy в Баваро, Пунта-Кана. Русская, английская и испанская версии; территория, события, меню, проживание, баня, хаммам и контакты. Основной способ связи — WhatsApp; также доступны телефон, email и Instagram.

Сайт на GitHub Pages: **https://imperil03.github.io/artenergy/**

## Разработка

Нужен Node.js 22 или новее. Внешних npm-зависимостей нет.

```sh
npm run dev -- --port 4173
npm run build
npm run check
npm test
```

`src/` содержит шаблоны, тексты, переводы и стили. `public/` — подготовленные медиа и локальный шрифт Golos Text с лицензией OFL. `dist/` — результат обычной сборки, он не хранится в Git.

Шапка и подвал находятся в общем каркасе `src/templates.mjs`; элементы и повторяющиеся секции — в `src/components.mjs`. Основные события используют один шаблон `birthday-page.mjs`. Поведение разделено на модули в `src/client/`, которые однократно запускает `app.js`. Порядок сборки задаёт `scripts/client-files.mjs`: браузер по-прежнему получает один CSS и один JS.

В готовый сайт копируются только используемые ресурсы и лицензия шрифта. Проверка охватывает ссылки, srcset, CSS-ресурсы, метаданные и целостность файлов; `npm test` проверяет навигацию, просмотр фото, языковые предпочтения и сборку URL. Команда `pages` выполняет сборку, проверки и тесты перед обновлением `docs/`.

## Обновление GitHub Pages

```sh
npm run pages
git add src public scripts package.json docs
git commit -m "Update ArtEnergy website"
git push
```

Pages публикует `main` → `/docs`. Команда `pages` собирает 54 HTML-файла (45 содержательных страниц, три 404 и шесть прежних SPA aliases), проверяет ссылки и ресурсы, затем обновляет `docs/`. Внутренние адреса и ресурсы адаптируются к префиксу `/artenergy/`.

Адрес сборки задаётся через `SITE_URL`; для этой публикации используется `https://imperil03.github.io/artenergy/`. Версия для просмотра содержит `noindex, nofollow`; поисковая индексация основного домена не переносится на GitHub Pages. Для другого целевого сайта настройте `SITE_URL` и `SITE_NOINDEX` при сборке.

Фотографии территории и часть медиа предоставлены для проекта. Тематические изображения событий и блюд созданы с помощью генерации; изображения проживания обработаны на основе предоставленных кадров. Хаммам — иллюстрация, происхождение сохранено в alt и метаданных изображения. Сайт не подтверждает бронирование и не отправляет сообщения автоматически.

## Контакты

Русская версия: `/kontakty/`, английская: `/en/contact/`, испанская: `/es/contacto/`. Данные находятся в `src/model.mjs`, тексты — в `contactPageCopy` из `src/translations.mjs`. Адрес копируется по действию посетителя, карта использует предоставленный адрес.

## Общие разделы

Площадка: `/ploshchadka/`, `/en/venue/`, `/es/espacio/`. Праздники: `/sobytiya/`, `/en/events/`, `/es/eventos/`. Проживание: `/prozhivanie/`, `/en/stays/`, `/es/alojamiento/`. Главное меню ведёт прямо на страницы разделов. Шаблоны — `src/section-pages.mjs`, дополнительные стили — `src/client/section-pages.css`.

Проживание объединено в одну подробную страницу на каждом языке: бунгало и апартаменты, фотографии, цены, WhatsApp и условия. Реализация — `src/lodging-page.mjs` и `src/client/lodging-page.css`. Для тестового GitHub Pages отдельные URL проживания и их перенаправления не создаются.

## Баня и хаммам

Общий раздел `/spa/`, `/en/spa/`, `/es/spa/` показывает оба варианта, цены и условия. Главное меню ведёт на общую страницу, карточки главной — к `#banya` или `#hammam`. Старые адреса сохранены как статические переходы к соответствующим блокам; в sitemap включён только общий раздел.

## SPA-процедуры

Массаж, пилинг тела и пропарка: `/spa-procedury/`, `/en/spa-treatments/`, `/es/tratamientos-spa/`. Обе SPA-страницы используют общий фотокомпонент услуг. Сведения для процедур — `src/content/spa-procedures.json`; цена и длительность показываются только после заполнения соответствующих полей подтверждёнными данными. Тексты находятся в `src/spa-procedures-copy.mjs`.

Меню «SPA и баня» содержит две страницы. Социальные ссылки контактов и подвала берутся из `src/socials.mjs`; незаполненные аккаунты не отображаются.
