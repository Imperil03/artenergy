# ArtEnergy

Статический многостраничный сайт площадки ArtEnergy в Баваро, Пунта-Кана. Русская, английская и испанская версии; территория, события, меню, проживание, баня и хаммам. Контактные действия открывают WhatsApp.

Сайт на GitHub Pages: **https://imperil03.github.io/artenergy/**

## Разработка

Нужен Node.js 22 или новее. Внешних npm-зависимостей нет.

```sh
npm run dev -- --port 4173
npm run build
npm run check
```

`src/` содержит шаблоны, тексты, переводы и стили. `public/` — подготовленные медиа и локальный шрифт Golos Text с лицензией OFL. `dist/` — результат обычной сборки, он не хранится в Git.

## Обновление GitHub Pages

```sh
npm run pages
git add src public scripts package.json docs
git commit -m "Update ArtEnergy website"
git push
```

Pages публикует `main` → `/docs`. Команда `pages` собирает 45 HTML-страниц, проверяет ссылки и ресурсы, затем обновляет `docs/`. Внутренние адреса и ресурсы адаптируются к префиксу `/artenergy/`.

Адрес сборки задаётся через `SITE_URL`; для этой публикации используется `https://imperil03.github.io/artenergy/`. Версия для просмотра содержит `noindex, nofollow`; поисковая индексация основного домена не переносится на GitHub Pages. Для другого целевого сайта настройте `SITE_URL` и `SITE_NOINDEX` при сборке.

Фотографии территории и часть медиа предоставлены для проекта. Тематические изображения событий и блюд созданы с помощью генерации; изображения проживания обработаны на основе предоставленных кадров. Хаммам помечен как иллюстрация. Сайт не подтверждает бронирование и не отправляет сообщения автоматически.
